# Bâtiments du quatrième arrondissement

Les données officielles ne sont pas inventées ni insérées manuellement.

Le workflow GitHub Actions « Préparer les données IGN » télécharge les emprises et hauteurs et crée ici un manifeste et des tuiles JSON.

En cas d'échec d'IGN, le workflow échoue et aucun bâtiment imaginaire ne remplace les données officielles.
